How to Install

Android only. Takes 2 minutes.

1

Download the APK

Tap the download button above. Your browser will save the file to your Downloads folder.

2

Allow Unknown Sources

Go to Settings → Security → Install Unknown Apps and enable it for your browser or file manager.

3

Open the APK File

Open your Downloads folder and tap the JijiChogoria.apk file to begin installation.

4

Tap Install

Follow the on-screen prompts and tap Install. The app will appear on your home screen.

5

Open & Login

Launch Jiji ya Chogoria, log in or create your account, and start buying and selling!
